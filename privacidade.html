Política de Privacidade — SaveSync

Última atualização: 11 de outubro de 2026

O que o SaveSync faz

O SaveSync é um programa de computador (Windows) que faz backup de arquivos de save de jogos no Google Drive do próprio usuário.

Dados acessados

  • Arquivos de save de jogos no computador do usuário, que são compactados e enviados ao Google Drive do próprio usuário.
  • Google Drive: com a permissão https://www.googleapis.com/auth/drive.file, o programa só acessa os arquivos e pastas que ele mesmo criou (pasta SaveSync). Nenhum outro arquivo do Drive é lido.
  • Endereço de e-mail da conta Google, exibido apenas na tela do programa para mostrar qual conta está conectada.

Onde os dados ficam

Os saves ficam somente no computador do usuário e no Google Drive do próprio usuário. O token de acesso do Google fica salvo apenas no computador do usuário. O SaveSync não tem servidores próprios e não envia, vende nem compartilha dados com terceiros.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

Use o botão “Desconectar” nas configurações do SaveSync, ou revogue o acesso em myaccount.google.com/permissions. Os backups podem ser apagados excluindo a pasta SaveSync do Google Drive.
